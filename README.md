# Автоматические проверки SLA
```sh
python -m unittest discover -s tests -v
```
Исходная версия корректна для шести базовых тестов. Задача дня — создать workflow, намеренно получить красный запуск в рабочей ветке, объяснить ошибку и восстановить зелёный запуск. Добавьте два теста отрицательного времени и неизвестного приоритета.
Шаблон workflow лежит в templates/ci.yml.txt. GitHub не запускает этот файл, пока он не перенесён в .github/workflows/ci.yml.
Ссылки на запуски записывайте в docs/ci-report.md.
